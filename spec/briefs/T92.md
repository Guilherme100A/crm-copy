- **AC-T92-01** Painel "Teste ao vivo" conversa com o agente (roteiro do FakeLlm via harness) e mostra habilidades disparadas, campos preenchidos e créditos.
- **AC-T92-02** Criação assistida mostra os estágios por SSE e os avisos; ao terminar, abre o agente com o banner "revise antes de publicar".
- **AC-T92-03** Aba Vozes: enviar 1–3 amostras, ouvir a prévia, manter ou excluir.
- **AC-T92-04** Ditado por voz nas instruções usa a transcrição (FakeStt) e insere o texto.

## O que as dependências entregaram (código na main)

### T79 — laboratório: `apps/api/src/routes/ai-agent-lab/index.ts` (serviço `packages/core/src/ai-agent-lab/service.ts`)
Leitura do run com `flows.view`; o resto com `flows.edit`. Erros de `AgentLabError` viram `ApiError` com `details.reason`: `not_found`→404, `validation|not_configured|invalid_audio`→422 `VALIDATION_ERROR`, `eval_cap|no_balance`→`QUOTA_EXCEEDED`, `create_in_progress`→409 `CONFLICT` (com `run_id`).
- `POST /api/ai-agents/:id/test-messages { text (1–4000), draft? }` → `TestMessageResult`: `blocks[{type:'text',text}]`, `audio`, `skills_fired[{tool, action_type, skill_id, input}]`, `fields_filled`, `collected`, `handoff`, `trace{model, instructions, knowledge_hits, tool_calls, finish, steps}`, `charged_credits`, `charged_tokens`, `usage`, `eval{used, limit}`.
- `DELETE /api/ai-agents/:id/test-messages` → `{ ok: true }` ("Limpar conversa").
- `POST /api/ai-agents/runs/estimate` → `{ estimated_tokens, estimated_credits, available_credits, enough }`.
- `POST /api/ai-agents/runs { pitch (≤8000), site_url? }` → 202 `{ run }`; `GET /api/ai-agents/runs/:runId` → `{ run }`.
  - `PublicRun` = `{ id, status: queued|running|completed|failed, stage: extract|compose|persist|null, stages_done, warnings (ex.: 'site_unread', 'empty_knowledge'), agent_id, error_message, created_at, updated_at }`.
- `POST /api/ai-agents/transcriptions` (multipart, campo `file`, ≤25 MB) → `{ text }`.
- Realtime: `ai_agent.run.updated { run: {id, status, stage, warnings, agent_id, error_message} }` (perm `flows.view`, `packages/shared/src/realtime/events.ts` linha ~228).

### T80 — vozes: `apps/api/src/routes/ai-voices/index.ts` (`flows.view` lê; `flows.edit` o resto)
- `GET /api/ai-voices?page&limit(≤100)`; `GET /api/ai-voices/:id` → `{ voice }`.
- `POST /api/ai-voices` multipart: `name`, `language` (`pt|en|es|hi`), 1–3 arquivos em `audios` (ou `audios[]`), até 10 MB cada (`VOICE_MAX_SAMPLES`, `VOICE_SAMPLE_MAX_BYTES`) → 201 `{ voice }`. Sem chave ElevenLabs → 422 `error_code: provider_not_configured`.
- `POST /api/ai-voices/:id/preview { text? }` → áudio binário (`audio/mpeg`), medido como `tts`.
- `POST /api/ai-voices/:id/keep` → `{ voice }` (status `kept`); `DELETE /api/ai-voices/:id` → `{ deleted, removed_from_agents[{id,name}], warning }`.
- `AiVoiceDto` = `{ id, name, language, status: pending|kept, provider, provider_voice_id, samples_count, samples, kept_at, created_at, updated_at }`.

## Atenção (achados do levantamento)
1. **Pontos de montagem fora dos Paths (todos da T88).** Peça ao Orquestrador a liberação ADITIVA, ou reporte BLOCKED parcial:
   - `features/agents/editor-page.tsx`: painel "Teste ao vivo" e banner "revise antes de publicar" (AC-01, AC-02);
   - `features/agents/tabs.tsx` (`InstructionsTab`): botão de ditado que insere o texto (AC-04);
   - `features/agents/list-page.tsx`: aba Vozes com envio/prévia/manter/excluir (AC-03) e botão "Criar com IA" (AC-02);
   - `routes/agentes/*.tsx`: registrar `ai_agent.run.updated` junto do `registerAgentsRealtime()` (handler em módulo lazy não entra no SSE já aberto, lição T53). Sem isso, use polling de `GET /api/ai-agents/runs/:runId` como fallback (ref §7, 1,2 s), mas o AC pede SSE.
   - Banner: não invente search param novo sem liberar `editorSearchSchema`; se usar, escolha um nome que não exista em outra rota (lição do `?status=`).
2. **Lacuna do harness, FakeLlm "congelado" (provável; confirme com um teste):** `aiAgentLabService(deps)` lê `deps.e2e.llm` UMA vez, ao montar a rota. O `POST /__e2e/reset` faz `deps.e2e.llm = new FakeLlm()` (`apps/api/src/e2e/index.ts`, `doReset`), e `/__e2e/llm/script` com `replace` também troca a instância. Depois de um reset, o roteiro vai para um FakeLlm e o laboratório usa outro. A correção (getter preguiçoso) é em `apps/api/src/routes/ai-agent-lab/index.ts`, fora dos Paths.
3. **Criação assistida no harness:** sem `aiAgentLabInline`, o run vai para a fila BullMQ `ai-agent-lab`. O worker in-process monta o serviço pelo env (`apps/worker/src/jobs/ai-agent-lab/index.ts`, `createCompanyLlmProvider` = chaves BYOK reais). `scripts/e2e/api.ts` não chama `configureAiAgentLab`. Precisa de `configureAiAgentLab({ db, redis, llm: <o FakeLlm do harness> })` ou `aiAgentLabInline: true` no `createApp` do harness. Fora dos Paths: peça a liberação de `scripts/e2e/api.ts`.
4. **Ditado (AC-04):** o STT padrão é `resolveStt` (Groq com a chave da empresa) e sai para a rede. O harness precisa de `aiLabStt: () => new FakeStt({ text: '…' })` (`packages/ai/src/testing/fake-voice.ts`) no `createApp` de `scripts/e2e/api.ts`.
5. **Vozes (AC-03):** o harness não injeta `aiVoicesProvider` nem `aiVoicesFetch`, então a clonagem e a prévia chamam a ElevenLabs real. Use o `FakeElevenLabsVoices` (`packages/core/src/ai-voices/testing/fake-elevenlabs.ts`, servidor local com `/v1/voices/add`, `DELETE /v1/voices/:id` e TTS) no harness. Também é preciso uma chave `elevenlabs` (`POST /api/ai-keys { provider:'elevenlabs', name, secret }`), senão a resposta é `provider_not_configured`.
6. **Dados para o teste ao vivo:** sem modelo resolvido a resposta é 422 `not_configured`. Copie o padrão de `tests/acceptance/T88/agents.e2e.ts`: chave `openai` + `model: { provider:'openai', model }` + `generated_prompt`. O `UsageGuard` cobra: sem saldo vem `no_balance`. Recarregue com `platform@demo.test` → `POST /api/platform/companies/:id/ai/topups { credits, note }`.
7. Nenhum E2E usou o laboratório pelo harness até agora: a T79 testou em processo (`tests/acceptance/T79/lab.test.ts`).
8. **Sobreposição:** nenhuma tarefa em andamento mexe em `features/agents`. A T102 (E2E final) vai depender dos testids desta.
